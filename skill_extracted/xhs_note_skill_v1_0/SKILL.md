# 小红书资料带货笔记母版生成 Skill v1.0

## 0. v1.0 定位

本 Skill 用于把用户已有的法语考试资料包、知识库、第三方帖子观点、爆款标题库，转化成可发布的小红书图文带货笔记。

v1.0 不做“万能小红书文案生成器”。v1.0 的核心是：

> 固定商品上下文 + 固定主链路 + 兼容性校验 + 同母版封面候选 + 内页卡片脚本 + 最后生成正文 caption。

v1.0 必须降低 AI 自由度，避免 AI 注意力丢失、跨考试混用、母版乱跳、标题骨架乱跳。

---

## 1. v1.0 核心产物

每次完整生成应输出：

1. 同一封面母版 + 同一标题母版下的 3 组封面候选；
2. 每组对应的小红书标题、标题来源、迁移逻辑、SEO 词、断行；
3. 用户选定 1 组后，生成 P1-P7 内页图片脚本；
4. 正文 caption；
5. tag；
6. 图片渲染说明，供 Web 工作台生成 PNG。

v1.0 默认产出 P1-P7。若内容量不足，不得硬凑 7 页；必须提示补充内容，或降级为 P1-P5 并在 manifest 中标记 `page_count_adjusted: true`。

## 2. v1.0 绝对规则

### 2.1 商品只选择一次

用户在 Step 1 选择商品后，商品进入全局上下文。后续任何步骤不得再次要求用户填写商品、资料包名称或“想卖什么”。

商品信息来自：

- `data/products.yml`
- `data/seo_tags.yml`

### 2.2 v1.0 先选主链路，不做任意组合

v1.0 不允许用户随意组合“商品 + 内容 + 封面母版 + 标题母版 + 内页结构”。

正确逻辑是：

```text
选择商品
↓
选择该商品下允许的主链路 chain
↓
内容来源、封面母版、标题母版、内页结构只能从 chain 允许范围内选择
```

主链路来自 `data/chains.yml`。

### 2.3 内容来源只决定“这篇讲什么”

内容来源不重新决定商品。

内容来源只有三类：

1. 预设卖点；
2. 知识库知识点；
3. 第三方帖子内容。

### 2.4 封面母版一旦选择，后续锁死

如果用户已经选择封面样式母版，后续 3 组封面候选必须全部使用同一个封面母版。

不得同时生成文档截图型、表格型、资料清单型、计划表型等其他母版。

### 2.5 封面标题母版一旦选择，后续锁死

如果用户已经选择封面标题格式母版或爆款标题，后续 3 组标题必须只在该标题骨架附近变体。

爆款标题不是独立自由入口。爆款标题必须先归类为一个 `title_template_id`，再在该标题母版下生成 3 个候选。

### 2.6 3 组结果不是 3 个方向

3 组结果只允许变化：

- 封面标题具体措辞；
- 标题断行；
- 小红书标题；
- SEO 长尾词嵌入；
- 局部布局微调；
- 正文承接角度的小幅差异。

3 组结果不允许变化：

- 商品；
- 主链路；
- 内容主方向；
- 封面母版；
- 封面整体样式；
- 封面标题母版；
- 标题骨架。

### 2.7 标题必须有来源

所有封面标题和小红书标题必须标注来源：

- 来自封面标题母版；
- 来自用户提供的爆款标题；
- 来自第三方帖子的真实痛点；
- 来自当前商品的真实卖点或知识点。

无来源的标题不得生成。

### 2.8 知识库知识点必须有具体内容

如果内容来源选择“知识库知识点”，用户必须提供具体内容片段。只有标签级信息时不得直接生成。

不够：

```text
important 的替换词
```

够用：

```text
important → essentiel / primordial / fondamental
problème → enjeu / difficulté / obstacle
je pense que → il me semble que / il convient de souligner que
```

### 2.9 第三方帖子模式只需要第三方内容

如果内容来源选择“第三方帖子内容”，用户只需要提供第三方帖子原文、截图文字或摘录。不得要求用户再次填写商品。

AI 自动完成：

- 提炼核心观点；
- 提炼真实痛点；
- 判断内容功能；
- 去掉不可直接复用的原帖表达；
- 迁移到已锁定商品和已选 chain 上。

若用户只给一句观点标签，不足以生成，提示补充原帖 1–3 段内容或截图文字。

### 2.10 内页不是正文拆分

内页图片文字必须是卡片脚本，不是把正文拆成多页。

每页只讲一个点，包含：

- 页面编号；
- 页标题；
- 核心结论；
- 支撑内容；
- 页面形式；
- 视觉继承说明。

### 2.11 正文 caption 最后生成

正文 caption 在封面标题和内页脚本完成之后生成。

正文只负责：

- 承接封面标题；
- 概括内页；
- 自然埋 SEO 词；
- 软转化；
- 输出 tag。

不得重新开启新主题。

### 2.12 图片中文字必须模板渲染

所有中文标题、正文、表格、清单、法语例句，必须由模板、画布、HTML/CSS、SVG 或 Canvas 渲染。

不得让生图模型直接生成最终文字。

生图 AI 只允许生成无文字背景层或装饰层。v1.0 默认不接生图 AI。

## 3. v1.0 六条主链路

v1.0 第一版不是 3 条链路，也不是无限自由组合。v1.0 固定为 6 条主链路。

链路配置详见 `data/chains.yml`。

### 3.1 DELF B2｜背范文不会迁移

- 商品：DELF B2 写作资料包
- 内容：背了范文，换题不会写
- 适合封面：白底蓝字痛点型 / 文档样张型
- 适合标题：努力无效型 / 反常识型 / 别再型
- 内页结构：痛点拆解型 / 样张展示型
- 禁止混入：CLB7、加拿大移民、TEF Canada、TCF Canada

### 3.2 DELF B2｜普通表达升级 B2 表达

- 商品：DELF B2 写作资料包
- 内容：important / problème / je pense que 等表达升级
- 适合封面：表格对照型 / 资料清单型 / 文档样张型
- 适合标题：别再型 / 错误提醒型 / 清单领取型
- 内页结构：表格对照型 / 清单干货型
- 禁止混入：CLB7、加拿大移民、TEF Canada、TCF Canada

### 3.3 DELF B2｜写作模板 / 句法库

- 商品：DELF B2 写作资料包
- 内容：开头句、观点句、让步句、总结句
- 适合封面：资料清单型 / 文档样张型 / 白底蓝字痛点型
- 适合标题：清单领取型 / 考前急救型 / 别再型
- 内页结构：清单干货型 / 样张展示型
- 禁止混入：CLB7、加拿大移民、TEF Canada、TCF Canada

### 3.4 DELF B2｜错题对照 / 扣分点

- 商品：DELF B2 写作资料包
- 内容：常见中式表达、低级表达、逻辑断裂、看似没错但不像 B2 的写法
- 适合封面：错题对照型 / 表格对照型 / 白底蓝字痛点型
- 适合标题：错误提醒型 / 别再型 / 反常识型
- 内页结构：错题对照型 / 表格对照型 / 痛点拆解型
- 禁止混入：CLB7、加拿大移民、TEF Canada、TCF Canada

### 3.5 TEF/TCF Canada｜TEF 还是 TCF 选考

- 商品：TEF/TCF Canada 备考资料包
- 内容：TEF 和 TCF 怎么选
- 适合封面：表格对照型 / 资料清单型
- 适合标题：对比选择型 / 清单领取型
- 内页结构：表格对照型 / 清单干货型
- 禁止混入：DELF B2 production écrite、DELF B2 范文、B2 写作资料包

### 3.6 TEF/TCF Canada｜30 天备考 / CLB7 路径

- 商品：TEF/TCF Canada 备考资料包
- 内容：30 天备考安排、CLB7 目标拆解、阶段任务和资料使用顺序
- 适合封面：计划表型 / 资料清单型 / 文档样张型
- 适合标题：路径规划型 / 考前急救型 / 清单领取型 / 努力无效型
- 内页结构：计划日历型 / 攻略路径型 / 清单干货型
- 禁止混入：DELF B2 production écrite、DELF B2 范文、B2 写作资料包

## 4. 状态机规则

v1.0 必须用状态机控制流程，不要靠大 prompt 让 AI 自己记。

最小状态字段：

```json
{
  "product_id": null,
  "chain_id": null,
  "content_source_type": null,
  "content_core": null,
  "cover_template_id": null,
  "title_template_id": null,
  "selected_variant_id": null,
  "page_template_id": null,
  "page_scripts": null,
  "caption": null,
  "tags": null
}
```

步骤校验：

```text
缺 product_id → 不能选择 chain
缺 chain_id → 不能选择内容来源
缺 content_core → 不能选择封面/标题
缺 cover_template_id → 不能生成封面
缺 title_template_id → 不能生成封面
缺 selected_variant_id → 不能生成内页
缺 page_scripts → 不能生成正文 caption
```

## 5. 常识冲突校验

### 5.1 商品和链路冲突

`product_id` 必须等于 chain 中配置的 `product_id`。

例如：

- `delf_b2_writing` 不得选择 `tef_tcf_30_day_clb7`；
- `tef_tcf_canada` 不得选择 `delf_b2_expression_upgrade`。

### 5.2 商品和术语冲突

DELF B2 写作资料包中，默认禁止出现：

- CLB7；
- 加拿大移民；
- TEF Canada；
- TCF Canada。

TEF/TCF Canada 资料包中，默认禁止出现：

- DELF B2 production écrite；
- DELF B2 范文；
- B2 写作资料包。

除非用户明确要求“比较不同考试”，否则不得混用。

### 5.3 内容和封面母版冲突

内容必须匹配 chain 允许的 `allowed_cover_templates`。

例如：

- 普通表达升级更适合表格对照型/资料清单型；
- TEF/TCF 选考更适合表格对照型；
- 30 天计划更适合计划表型/资料清单型。

### 5.4 内容和标题母版冲突

标题母版必须来自 chain 允许的 `allowed_title_templates`。

例如：

- important 替换词不适合“TEF 还是 TCF？”这种对比选择型；
- TEF/TCF 选考不适合“别再把 important 写到底”；
- 30 天计划不适合单词替换类标题。

### 5.5 内容量不足

若知识点或第三方帖子内容不足，不得硬凑内页。

系统必须提示：

1. 补充更多具体内容；或
2. 降级成 P1-P5 短图文；或
3. 改选更适合的小链路。

## 6. 日常生产流程

### Step 1：选择商品

用户选择一个商品。系统读取商品上下文。

### Step 2：选择主链路

用户从该商品允许的 6 条主链路中选择一条。

### Step 3：选择内容来源

内容来源必须在该 chain 的 `allowed_content_source_types` 中。

### Step 4：输入/选择内容

- 预设卖点：从商品对应卖点中选择；
- 知识库知识点：输入具体内容片段；
- 第三方帖子内容：输入原文、摘录或截图文字。

### Step 5：选择封面母版

只能从 chain 的 `allowed_cover_templates` 中选择。

### Step 6：选择标题母版 / 爆款标题

只能从 chain 的 `allowed_title_templates` 中选择。

若用户选择爆款标题，系统必须先把爆款标题归类到 chain 允许的标题母版中。

### Step 7：生成 3 组封面标题 + 小红书标题

每组必须包含：

- 封面标题；
- 推荐断行；
- 小红书标题；
- 标题来源；
- 标题迁移逻辑；
- SEO 长尾词；
- 封面布局说明。

### Step 8：用户选定 1 组

用户选定 1 组后，后续内页和正文必须继承该组的封面标题、小红书标题、内容方向和 SEO 词。

### Step 9：生成内页结构和每页脚本

内页结构只能从 chain 的 `allowed_page_templates` 中选择。

P2 的作用是承接 P1 封面。P2 不能一上来硬卖资料包。

推荐节奏：

```text
P1：封面，负责点击
P2：承接痛点，让用户觉得“说的就是我”
P3-P5：展开内容价值，给对照、清单、样张或方法
P6：自然带到资料包对应模块
P7：适合谁 / 使用提醒 / 轻 CTA
```

### Step 10：生成正文 caption + tag

正文 caption 必须最后生成。正文需要像备考经验分享，不要像硬广。

## 7. 图片生成原则

图片分三层：

1. 背景层：CSS/Canvas 或生图 AI 生成。若使用生图 AI，必须无文字；
2. 文字层：标题、表格、清单、法语例句，必须由画布/模板渲染；
3. 组件层：表格、文档卡片、清单卡片、标注、页码等。

v1.0 默认使用模板/画布渲染，不接生图 AI。生图 AI 进入未来规划。

## 8. v1.0 不做事项

v1.0 不做：

- 自动发布；
- 多账号管理；
- 数据回流；
- 竞品爬虫；
- 用户登录；
- 在线支付；
- 批量日更；
- 生图 AI 背景；
- 上传竞品封面自动识别；
- 任意组合生成器。

v1.0 只做：

> 6 条固定主链路 + 状态机 + 兼容性校验 + 3 张同母版封面候选 + 内页脚本 + caption/tag + PNG 导出。

## 9. 未来规划（写入 v1.0 首文档，但 v1.0 不实现）

### v1.1：竞品母版扩展

目标：从真实竞品笔记中稳定扩充母版库。

计划：

- 支持上传竞品封面；
- AI 只分析版式，不直接改图；
- 提取背景颜色、标题位置、字号层级、信息密度、装饰元素；
- 生成临时母版；
- 用户肉眼对比竞品和新封面。

不允许：像素级抄袭、不改字直接使用竞品图、保留竞品账号标识。

### v1.2：生图 AI 背景增强

目标：让封面更有质感，但不破坏文字可控性。

规则：

- 生图 AI 只生成无文字背景；
- 中文、法语、表格、清单全部由画布/模板渲染；
- 生成背景时必须绑定封面母版；
- 背景不得抢标题主次。

### v1.3：母版推荐而非任意选择

目标：用户输入内容后，系统推荐 2-3 个兼容母版。

规则：

- 推荐只能从 chain 允许列表中产生；
- 用户选定后仍然锁死；
- 不允许 3 个封面候选使用不同母版。

### v1.4：爆款标题库结构化

目标：把用户 70+ 爆款标题转成可迁移标题资产。

每条标题必须结构化为：

- 原标题；
- 标题类型；
- 标题骨架；
- 心理钩子；
- 适合链路；
- 禁用链路；
- 迁移示例。

### v2.0：半自动日更工作流

目标：从“单条笔记生成器”升级成“日更生产线”。

可能能力：

- 每天根据商品和链路生成候选选题；
- 支持素材库；
- 支持批量预览；
- 支持人工确认后排期；
- 支持手动录入数据反馈；
- 根据收藏/点击表现调整母版优先级。

v2.0 仍不建议一开始做自动发布。先做人工确认的半自动生产线。

## 10. 最终验收标准

v1.0 合格的标准：

1. 商品只选一次，后面不再问商品；
2. 必须先选商品，再选该商品下的 chain；
3. 封面母版和标题母版只能从 chain 允许范围选；
4. 3 张封面候选必须同母版、同标题骨架；
5. DELF B2 不混入 CLB7 / TEF / TCF；
6. TEF/TCF Canada 不混入 DELF B2 范文语境；
7. 知识点不足时不硬凑 7 页；
8. P2 承接封面，不直接硬卖；
9. P6-P7 才自然带商品；
10. 正文 caption 最后生成；
11. 所有中文字由模板/画布渲染；
12. 可以导出 PNG、caption、tags、manifest、preview.html。
