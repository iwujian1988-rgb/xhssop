# 已确认的设计决策

## 暂缓：约束式自适应排版

模板视觉暂时停止调整。后续恢复模板开发时，不再依赖固定 CSS 硬塞动态文字，也不要求 LLM 精确控制字数。

目标方案：

1. 在固定画布中生成多套候选布局（宽松、标准、密集，以及适用的单列、双列、三列版本）。
2. 等字体加载完成后，实际测量文字块的宽高。
3. 用二分搜索在模板允许的字号范围内寻找最大可用字号。
4. 圆点、线条、标签和文字必须在同一布局单元中流式排版，避免独立绝对定位。
5. 检查溢出、裁切、遮挡、重叠、最小字号和安全边距。
6. 内容仍放不下时，将低优先级内容移入内页，禁止无限缩小字号。
7. 从合格方案中选择字号最大、信息密度最接近参考图的一版。

该方案保留，等主内容流程闭环后再实施。

## 当前优先级：先闭环内容流程

主流程采用：竞品创作卡/封面模板 -> 可用种子 -> 精确知识证据 -> 内容任务单 -> 笔记标题 -> 封面标题及结构化封面内容 -> 内页 -> 正文和标签 -> 一致性审核。

种子是经过验证的选题任务单，不直接等于最终标题。种子提供人群、场景、痛点、需求、商品承接和知识范围；75 个标题公式继续负责点击机制；封面标题按封面角色单独生成。
