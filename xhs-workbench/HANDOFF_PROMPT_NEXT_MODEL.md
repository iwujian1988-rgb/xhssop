## 三、已经确定的普通模式链路

普通模式的流程是：

```text
用户先选择封面
-> AI生成3个不同方向的选题
-> 用户选择1个选题
-> 锁定主题
-> 生成内容任务单
-> 生成正文和内页
-> 单独生成和优化文字标题、封面标题
-> 使用已选封面模板排版
-> 生成标签
-> 最终检查
```

普通模式的选题方向包括：

- 大痛点型：用户正在经历的具体问题；
- 省时路径型：少整理、少试错、快速找到重点，不承诺考试结果；
- 具体方法型：一个明确、可以展开的学习方法或操作方法。

用户选择封面后，封面提供视觉承载边界，但不能强行决定商品主题。选题确定以后，正文、内页、标题、标签都不能中途换成另一个主题。

## 四、选题阶段共识

选题阶段使用以下信息：

1. 商品信息；
2. 商品能力；
3. 购买者地图；
4. 当前封面视觉形式和承载能力；
5. 历史去重信息；
6. 当前生成要求。

商品能力和商品模块必须分层：

- 商品能力：商品能够帮助用户完成什么；
- 支持模块：商品中哪些资料支持这个能力。

例如：

```json
{
  "能力": "提供作文自查的方法和对照维度",
  "支持模块": ["评分对照", "错题对照", "写作检查清单"]
}
```

购买者地图至少区分：

- 用户阶段；
- 真实状态；
- 购买动机。

事实卡和相关资料是软约束，不是选题硬门槛。普通模式找不到完全对应的事实时，可以让 AI 原创一般解释、方法和例子，但不能把原创内容说成官方考试规定，也不能声称商品有不存在的模块、服务或功能。

## 五、最近确认的最终标题优化节点

标题节点必须在正文和内页完成之后，不能只拿选题标题来写。

它的主要入参是：

- 商品信息；
- 购买者地图；
- 已确定选题；
- 选题阶段已有标题草稿；
- 正文；
- 内页摘要；
- 当前封面模板、视觉形式和容量；
- 当前商品搜索词；
- 当前商品历史标题；
- 本次要求的标题数量和字数限制。

特别注意：之前生成的选题标题、文字标题草稿、封面标题草稿都应该传给最终标题优化节点，但只是参考，不是必须保留。标题优化节点可以重写它们。

### 标题节点必须分别输出

1. 文字标题：负责笔记点击，可以更完整；
2. 封面标题：负责缩略图第一眼建立用户关系，必须更短、更醒目、适合模板容量。

每组文字标题和封面标题必须配对，不能出现数量不一致、封面标题属于另一篇内容的问题。

标题方向应拉开差异：

- 资料/大全型：数量、时间、完整度、时效性、实用值、收藏价值；
- 大痛点型：用户确实正在经历的问题；
- 情绪型：后悔、意外发现、焦虑缓解、松一口气、忍不住分享；
- 反常识型：指出常见但不一定有效的准备方式；
- 结果/省时路径型：少走弯路、快速找到重点；
- 真人陈述型：像用户自己在分享整理和发现。

用户不喜欢以下标题：

- 机械的“XXX？先XXX”；
- “资料太散”这类未经确认的抽象痛点；
- “写作任务”“格式正在拖后腿”等不自然表达；
- 课程目录式标题；
- AI总结腔；
- 只有关键词、没有用户关系的标题；
- 过度啰嗦的标题。

用户喜欢的感觉是：

- 有法语/DELF B2身份；
- 有真实用户状态；
- 有网感和热情；
- 有冲突、反常识、后悔、发现、推荐或捷径感；
- 资料型标题突出数量、时间、最新、最全、实用值和收藏价值；
- 像真人发帖，不像产品说明书。

标题优化不能只写“生成爆款标题”，必须把正文、内页和用户状态交给 AI，让它根据真实内容改写。

## 六、标题质量与拦截原则

不要把“标题不够爆款”当成整篇任务失败。

### 可以局部返修

- 标题不说人话：只返修标题；
- 情绪不够强：只返修标题；
- 封面标题太长：只返修封面标题；
- 文字标题和封面标题重复：只重新生成标题；
- 标题承诺正文没有接住：只修标题或承接段。

### 只提醒并放行

- 情绪一般；
- SEO偏弱；
- 带货力度偏弱；
- 没有命中全部事实卡；
- 网感不够强；
- 购买理由不够充分。

### 才能硬拦截

- 完全跑题；
- 明显错误的法语例句或释义；
- 虚构商品功能、服务、资质或用户反馈；
- 封面渲染失败、图片丢失、文字被遮挡且无法恢复；
- 内容无法正常生成；
- 标题严重超过平台或模板容量且无法缩短。

## 七、封面、内页和标题的关系

```text
选题决定：这篇讲什么
内容任务单决定：正文和内页讲什么
标题节点决定：用什么话吸引用户
封面模板决定：标题如何呈现
排版程序决定：字号、折行、位置和遮挡
```

不要让标题节点重新决定封面样式，也不要让封面样式把已确定选题改掉。

现有封面视觉组件已经经过多轮调整，除非用户明确要求，不要重做整套封面。尤其不要把已有封面重新改成一套新的 HTML 风格。

封面标题文字过长时，优先重新生成短标题，不要无限缩小字体。封面标题必须在小红书缩略图中可读。
